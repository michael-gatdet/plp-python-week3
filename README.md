## Bug Hunt

bug_hunt.py fixes three bugs in a "while" loop and correctly calculates the sum of numbers from 1 to 5.

The hardest bug to find was the incorrect "while" loop condition because the program could run without showing an error message but still produce the wrong answer. I knew something was wrong because the required answer was 15, but the program produced a different result, so I checked the loop condition and found that 5 was not being included.
